# Codes for the article *"Convergence to good non-optimal critical points in the training of neural networks: Gradient descent optimization with one random initialization overcomes all bad non-global local minima with high probability"*

This repository accompanies the article *"Convergence to good non-optimal critical points in the training of neural networks: Gradient descent optimization with one random initialization overcomes all bad non-global local minima with high probability"* by Shokhrukh Ibragimov, Arnulf Jentzen, and Adrian Riekert, which is currently available as a preprint on the [arXiv](https://arxiv.org/abs/2212.13111).
> The python codes in the 'Codes'-directory implement the numerical examples from Section 4 in the paper.
